# icrmahin-theme for Zed

Three dark variants for Zed: Basalt, Dusk, and Moss.

## Install (development)

1. In Zed, run **zed: install dev extension** from the command palette.
2. Select this folder.
3. Open the theme selector (`Cmd+K Cmd+T` on macOS, `Ctrl+K Ctrl+T` elsewhere) and pick an icrmahin-theme variant.
